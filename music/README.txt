راهنمای آپلود در GitHub Pages

1) فایل index.html را در ریشه Repository قرار بده.
2) آهنگ خودت را داخل همین پوشه music آپلود کن.
3) اسم فایل آهنگ را دقیقاً این بگذار:
   our-song.mp3
4) ساختار نهایی باید این باشد:
   index.html
   music/our-song.mp3
5) در GitHub برو به Settings → Pages و Branch اصلی (main) را برای انتشار انتخاب کن.

نکته: مرورگرها معمولاً پخش خودکار صدا را بدون لمس کاربر اجازه نمی‌دهند؛ بنابراین بعد از باز شدن سایت روی دکمه «♪ آهنگ ما» بزن.
